# Resume Generator

> Transforme um currículo em texto em um PDF profissional com apenas um clique.

## O problema

Adaptar um currículo para diferentes oportunidades costuma ser um processo repetitivo.

Mesmo quando o conteúdo já está pronto, ainda é necessário organizar informações, ajustar o layout, alinhar espaçamentos e exportar um PDF antes de enviar a candidatura.

Esse projeto elimina essa etapa.

Basta colar um currículo em texto e gerar instantaneamente um documento profissional, limpo e pronto para ser enviado.

---

## Objetivo

O Resume Generator foi criado para tornar a geração de currículos extremamente simples.

Seu único propósito é converter um currículo em texto em um PDF bem estruturado, mantendo uma apresentação profissional e consistente.

Sem edições manuais.

Sem ferramentas de design.

Sem configurações complexas.

---

## Como funciona

O processo é simples:

1. Abra a aplicação.
2. Cole o conteúdo completo do currículo no campo disponível.
3. Clique em **Gerar PDF**.
4. Faça o download do arquivo pronto.

Todo o restante acontece automaticamente.

---

## Principais características

* Conversão instantânea para PDF.
* Layout profissional e consistente.
* Compatível com sistemas de recrutamento (ATS).
* Interface simples e intuitiva.
* Geração com apenas um clique.
* Projeto leve, rápido e focado em produtividade.

## Executando o projeto

Clone o repositório:

```bash
git clone <repositorio>
```

Entre na pasta do projeto:

```bash
cd resume-generator
```

Instale as dependências:

```bash
npm install
```

Inicie a aplicação:

```bash
npm run dev
```

Depois, abra o endereço informado no terminal e utilize normalmente.
